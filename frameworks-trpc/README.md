<h2>Speakeasy tRPC OpenAPI Example</h2>

This example tRPC app demonstrates Speakeasy-recommended practices for generating clear OpenAPI specifications and SDKs, using a Train Travel API as the domain.

The API covers finding train stations, searching for trips, managing bookings, and processing payments.

## Project structure

- `server/` contains the Express app, tRPC router, mock database, and OpenAPI generation entrypoints.
- `shared/` contains Zod schemas and inferred types shared across the sample.
- `client/` contains a small typed tRPC client example that imports the server router type only.
- `sdk/` contains the generated SDK output.

## Prerequisites

You need to have [Node.js](https://nodejs.org/) installed on your system to run this project.

To generate an SDK, you'll also need the Speakeasy CLI installed, or use the Speakeasy dashboard.

## Installation

To install the application on your local machine:

1. Clone the repository:
```bash
git clone https://github.com/speakeasy-api/examples.git
```

2. Navigate into the directory:
```bash
cd examples/frameworks-trpc
```

3. Install all dependencies:
```bash
npm install
```

4. [Install Speakeasy CLI](https://github.com/speakeasy-api/speakeasy#installation):
```bash
brew install speakeasy-api/homebrew-tap/speakeasy
```

## Running the application

Start the server:

```bash
npm run start
```

The API will be available at `http://localhost:3000`.

The REST-like endpoints generated by `trpc-to-openapi` are mounted at `http://localhost:3000/api`, while the native tRPC endpoint remains available at `http://localhost:3000/api/trpc`.

If you want a small typed client example for the native tRPC endpoint, see `client/example.ts`.

### Working with the OpenAPI specification

To generate an OpenAPI 3.1 spec in JSON format, run:

```bash
npm run generate-openapi
```

This writes `openapi-spec.json`, which starts with `"openapi": "3.1.0"`.

Additionally, you can generate both the specification file and a TypeScript SDK for your API using:

```bash
npm run generate-openapi-and-sdk
```
